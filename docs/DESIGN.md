# 《奶蛙：笑到最后》游戏设计方案 v0.1

> 一句话：3D 低多边形 + 双摇杆射击 + 30 分钟肉鸽生存。奶蛙用"热梗弹幕"把一切让人笑不出来的东西打爆，肥嘟嘟在旁边用袋鼠拳补刀，攒满笑点后放出大招"捧腹大笑"。

## 1. 从顶级肉鸽里借什么

| 游戏 | 它做对的事 | 我们拿来做什么 |
|---|---|---|
| Vampire Survivors（吸血鬼幸存者） | 30 分钟一局；怪物数量/血量/速度随时间上涨；武器满级 + 指定被动 = **进化**，初始武器大约撑到第 10 分钟，之后靠进化活命（[来源](https://rappy-world.com/guide/vampire_survivors_weapon_evolution_guide_best_combos_to_unlock)） | 30 分钟时间轴、进化系统、Boss 宝箱 |
| 20 Minutes Till Dawn | **手动瞄准**的双摇杆射击 + 升级卡；角色 × 武器 × 升级三者组合出流派（[来源](https://fantasywarden.com/games/20-minutes-till-dawn-builds)） | 主武器手动瞄准，升级会改变子弹行为 |
| Brotato（土豆兄弟） | 竞技场有边界，build 对胜负影响极大；属性有取舍 | 有边界的场地（不能无限风筝）、"代价型"卡牌 |
| Hades | **双神祝福（Duo Boon）**：拿齐两个神的指定祝福才会出现，能改写整局（[来源](https://www.cbr.com/hades-duo-boon-guide/)）；Heat 难度系统 | 奶蛙技能 × 肥嘟嘟技能 = **合体技**；"胆子肥嘟嘟"挑战难度 |
| Halls of Torment | 前 5 分钟最难，之后靠 build 起飞（[玩家反馈](https://steamcommunity.com/app/2218750/discussions/0/4635988093614273522/)） | 把"前期选择决定后期"的感受做强 |

设计原则（参考 [一份 roguelite GDD 的观点](https://github.com/CristianVegara/roguelite/blob/main/GAME_DESIGN_DOCUMENT.md)：纯 "+5% 伤害" 不产生任何有意思的决策）：
1. **每张卡都要改变"怎么玩"**，纯数值卡占比 < 30%。
2. **前期的分叉要不可逆**：第 5 级选攻击形态，第 20 级形态突变，选了就回不去。
3. **难度靠机制压人**，不只靠堆血量：包围、冲锋、远程、弹幕墙、只能打背后的盾兵。

## 2. 核心循环

```
移动躲避（左摇杆） → 瞄准射击热梗弹（右摇杆） → 怪物掉落"笑点结晶"(经验)
      ↑                                              ↓
  难度随时间上涨  ←  三选一升级卡（改变攻击形态/技能/被动）  ←  升级
                                                      ↓
                              击杀累积"笑点值" → 满了放大招"捧腹大笑"
```

一局 30:00，活到最后并击败最终 Boss 即通关。死亡后结算"笑点币"，解锁新角色/新形态（轻量局外成长，存 localStorage）。

## 3. 角色

### 奶蛙（主角，玩家控制）
- 造型：黄色圆滚滚小青蛙，大嘴，豆豆眼。用球体 + 胶囊体拼成低模，卡通描边着色。
- 动画全靠代码做挤压拉伸（squash & stretch）：走路一弹一弹，被打时压扁，升级时笑到全身发抖。
- 普通攻击：**热梗弹**，子弹本身就是 3D 漂浮的文字："哈哈哈""绷不住了""6""典""急了""破防了""尊嘟假嘟"……每发随机，击中时文字炸成碎字。

### 肥嘟嘟（第二主角，AI 搭档 / 可解锁为可操控角色）
- 造型：黄色胖袋鼠，戴拳击手套（袋鼠拳击，近战定位天然成立）。
- 默认是跟随玩家的 AI 搭档：
  - **袋鼠拳**：自动打身边最近的怪，三连击带击退。
  - **嘲讽"你胆子真是肥嘟嘟的！"**：怪物太靠近奶蛙时，肥嘟嘟大喊这句，把周围怪的仇恨拉到自己身上（它血厚，会被打晕一会儿然后爬起来）。
  - **背刺**：肥嘟嘟会绕到怪物背后打，背后伤害 ×2。
- 肥嘟嘟有自己的升级卡分支（见 §5.4），走"肥嘟嘟流"的玩家等于玩召唤/近战流。
- 第二局起可以解锁"肥嘟嘟主控模式"：玩家操控袋鼠，奶蛙坐在育儿袋里帮你射击（角色互换，玩法完全不同：近战跳跃流）。

## 4. 操作（双摇杆，三端通用）

| 动作 | 电脑 | 手机 | 手柄 |
|---|---|---|---|
| 移动 | WASD | 左半屏虚拟摇杆（触点即中心，浮动） | 左摇杆 |
| 瞄准+射击 | 鼠标方向，按住左键射击（可切换自动射击） | 右半屏虚拟摇杆，推动即射击 | 右摇杆 |
| 冲刺（无敌帧 0.25s） | 空格 | 右下按钮 | RB |
| 大招"捧腹大笑" | Q | 笑点满时屏幕中间出现会抖动的奶蛙头像按钮 | Y |
| 暂停 | Esc | 右上角 | Start |

- 手机端加**轻度瞄准吸附**（右摇杆方向 ±12° 内有怪就吸过去）。
- 横屏为主，竖屏提示旋转。
- 手柄用浏览器 Gamepad API，几乎零成本。

## 5. 成长系统（重点）

### 5.1 升级节奏
- 目标：约 2:30 到 Lv5，约 10:00 到 Lv20，约 20:00 到 Lv40，30:00 约 Lv60。
- 每次升级三选一（幸运属性高时四选一）。每局有 **重抽 ×3、封禁 ×2、跳过** 资源（跳过给少量回血）。
- 卡牌稀有度：普通（白）/ 稀有（蓝）/ 史诗（紫）/ 传说（金），金卡出现时奶蛙笑声变调。
- 槽位上限：**主动技能 6 个 + 被动 6 个**，强制取舍。

### 5.2 攻击形态（不可逆分叉，回应"升级后攻击方式变化"）

**Lv5 第一次形态选择**（三选一，从下列中随机出三个）：

| 形态 | 梗 | 手感 | 流派 |
|---|---|---|---|
| 哈哈哈机关枪 | "哈" | 射速 ×3、单发伤害 ×0.4、带散布 | 机关枪流 |
| 绷不住了激光 | "绷" | 持续光束，伤害随照射时间叠加 | 持续输出流 |
| 6666 回旋镖 | "6" | 飞出去再飞回来，往返都造成伤害 | 走位流 |
| "典"字大锤 | "典" | 射速很慢的巨大文字，落地爆炸 | 爆发流 |
| 复读机 | "+1" | 每发子弹 0.15s 后自动重复两次 | 叠特效流 |

**Lv20 形态突变**（在已选形态上二选一）：
- 哈哈哈机关枪 → **加特林·笑到停不下来**（越射越快，停火会过热）或 **霰弹·哈哈哈哈哈**（近距离一喷七发）
- 绷不住了激光 → **三相绷不住**（三道光束）或 **绷断了**（光束结束时整条线爆炸）
- 6666 回旋镖 → **666 环绕**（常驻环绕身体）或 **6 翻了**（命中后分裂成更小的 6）
- "典"字大锤 → **典中典**（爆炸后原地再落一个）或 **典·陨石**（自动砸向最密集的怪群）
- 复读机 → **人类的本质**（重复次数 +3，伤害递减）或 **复读风暴**（重复弹改为追踪）

### 5.3 主武器改造卡（普通升级里出现，所有形态通用）
回应"可以从后面攻击""三发多发"：

| 卡 | 效果 | 上限 |
|---|---|---|
| 多发 +1 | 扇形多一发 | +4 |
| 屁股也在笑 | 向背后同时射一发 | 1 |
| 左右开弓 | 两侧各射一发 | 1 |
| 笑出八方 | 每第 5 次攻击变成 8 方向环射 | 1 |
| 穿透 +1 | 子弹多穿一个怪 | +3 |
| 弹弹弹 | 子弹碰到场地边缘或障碍物反弹 | +2 |
| 笑裂了 | 命中后分裂成 2 颗小字 | 1 |
| 追着笑 | 子弹轻微追踪 | 1 |
| 射速/伤害/弹速/体积/暴击 | 纯数值（每张都要大幅度，+15% 起） | 多级 |

每种改造对每种形态都要定义清楚行为，例如"多发 +1"对激光 = 多一道光束，对大锤 = 多砸一个落点。这是实现时的主要工作量之一。

### 5.4 主动技能（自动释放，技能流的核心）

| 技能 | 效果 | 进化条件（技能满级 + 指定被动） | 进化后 |
|---|---|---|---|
| 尬笑光环 | 身边持续伤害圈 | + 厚脸皮（护甲） | **社死领域**：圈内敌人受伤 +30% |
| 哈字护盾 | 几个"哈"字绕身旋转 | + 加速 | **哈哈哈哈龙卷风** |
| 芭比Q了 | 敌人死亡时原地着火爆炸 | + 泰裤辣（火伤） | **烤全场**：爆炸可连锁 |
| 退！退！退！ | 周期性击退冲击波 | + 肺活量（范围） | **退退退退退**：击退 + 眩晕 |
| 一整个大无语 | 随机区域减速 | + 冷却缩减 | **无语凝噎**：区域内冻结 2s |
| 表情包轰炸 | 天上随机砸表情包 | + 幸运 | **表情包雨**：数量 ×3，优先砸精英 |
| 栓Q | 闪电链，弹跳 4 次 | + 暴击 | **栓Q栓Q栓Q**：弹跳无限，直到伤害衰减为 0 |
| 尊嘟假嘟 | 每 10s 抛硬币：伤害 ×2 或 回血 | + 幸运 | **尊嘟**：两种效果同时生效 |

### 5.5 肥嘟嘟分支（召唤/近战流）
- 袋鼠拳等级（连击数、击退）
- 胆子肥嘟嘟（嘲讽范围、嘲讽期间肥嘟嘟减伤）
- 跳跳冲击（肥嘟嘟跳起砸地）
- 育儿袋（帮你吸经验、偶尔吐出回血果）
- 分身袋鼠（多一只小肥嘟嘟）

### 5.6 合体技（Hades 双神祝福式，传说卡）
奶蛙技能 + 肥嘟嘟技能都达到要求后才可能刷出：
- 芭比Q了 + 跳跳冲击 → **烧烤跳跳**：肥嘟嘟每次落地留下火圈
- 栓Q + 袋鼠拳 → **电拳**：每拳都带闪电链
- 退退退 + 胆子肥嘟嘟 → **你胆子真是肥嘟嘟的！！**：嘲讽变成全屏冲击波

### 5.7 胆子肥嘟嘟契约（代价卡，回应"难度够高"并给高手加码）
每 5 级有一次机会出现红色卡，例如：
- 伤害 +40%，但怪物移速 +20%
- 立即升 2 级，但最大血量 -25%
- 经验 +50%，但精英出现率翻倍

拿红卡时肥嘟嘟会说"你胆子真是肥嘟嘟的"。这个梗本身的意思（胆子太大）正好对应"冒险换收益"。

## 6. 大招："捧腹大笑"

**充能**：击杀加笑点，连杀（3 秒内不断击杀）加成更高，精英/Boss 加很多。前期约 3 分钟一次，后期约 1 分钟一次。不会随时间自动回复，必须靠打怪攒。

**释放流程（总长约 1.5s 演出 + 8s 巨大化）**：
1. **定格**：全场时间暂停，画面去色。
2. **动漫切镜**（实时渲染 + HTML/CSS 叠层，不用视频文件）：屏幕裂成漫画分镜，放射状速度线，镜头推到奶蛙脸上，大字"捧 腹 大 笑 ！！"砸下来，肥嘟嘟在角落小格子里喊"你胆子真是肥嘟嘟的！"。
3. **巨大化**：奶蛙放大到 5 倍，笑到全身狂抖，屏幕震动。
4. **冲击波**：每一声"哈"放出一圈扩散的冲击波环（文字环），伤害 = 当前等级 × 系数，基本清屏，对 Boss 打出大量伤害。
5. 巨大化 8 秒内无敌，移动会踩扁小怪，结束时笑晕倒地 0.5s（还原梗：笑晕了）。

**大招升级卡**：笑到岔气（持续 +3s）、传染笑（被冲击波杀死的怪也会笑着爆炸）、笑出腹肌（充能 -25%）。

## 7. 敌人：一切让人笑不出来的东西

题材上，奶蛙代表"笑"，敌人是各种让人"emo"的东西。这样所有梗都有统一的世界观。

| 敌人 | 出现 | 行为 |
|---|---|---|
| emo 小乌云 | 0:00 起 | 直线追人，量大 |
| 周一 | 2:00 起 | 停顿后高速冲锋，需要冲刺躲 |
| 已读不回 | 4:00 起 | 远程，吐出聊天气泡子弹 |
| 作业本 | 6:00 起 | 被打死分裂成 3 张卷子 |
| 差评 | 8:00 起 | 前方有盾，**只能从背后/侧面打**（"屁股也在笑"、肥嘟嘟背刺、反弹弹有用武之地） |
| 闹钟 | 12:00 起 | 靠近后倒计时自爆 |
| 黑眼圈 | 16:00 起 | 给周围怪加速加血 |
| 改需求 | 22:00 起 | 精英，每隔几秒把你的子弹变成它的子弹（短时间） |

**精英**：随机词缀（巨大、加速、护盾、死亡爆炸、召唤），金色描边，必掉宝箱。

**Boss**：
- 10:00 **甲方爸爸**：发射"改需求"弹幕，血量 50% 时召唤"再改一版"小怪
- 20:00 **KPI 巨像**：地面出现柱状图形状的升起攻击，需要走位
- 30:00 最终 Boss **笑不出来先生**：会吸走你的笑点值，打败他才通关

**特殊事件（抽象名场面）**：
- **弹幕风暴**（12:00、24:00）：成排的 B 站风格弹幕文字横扫整个场地，像墙一样，要么躲，要么打出缺口。
- **包围圈**（8:00、18:00）：一圈怪从四周同时收缩。
- **盲盒宝箱**：开箱有抽卡动画，可能开出 1/3/5 个升级。

## 8. 难度曲线（30 分钟）

设 m = 当前分钟数：
- 怪物血量倍率 ≈ `1 + 0.15·m + 0.004·m²`（30 分钟约 ×9）
- 同屏怪物上限 ≈ `40 + 12·m`（30 分钟约 400）
- 刷怪预算每秒 ≈ `2 + 0.5·m`，按怪物"费用"分配，每分钟的刷怪表单独配置（JSON）

| 阶段 | 时间 | 同屏 | 设计意图 |
|---|---|---|---|
| 入门 | 0–3 | ≤ 70 | 教操作，2:30 左右选第一个形态 |
| 成型 | 3–10 | ≤ 160 | 冲锋怪 + 远程怪逼走位，5:00 第一只精英，10:00 Boss |
| 考验 | 10–15 | ≤ 220 | 盾怪要求有绕背手段，弹幕风暴，Lv20 形态突变 |
| 爆发 | 15–20 | ≤ 280 | 精英常态化，build 没成型的玩家在这里开始崩，20:00 Boss |
| 地狱 | 20–30 | ≤ 400 | 自爆+改需求+双弹幕风暴，30:00 最终 Boss |

**为什么能"够难"**：
- 回血非常稀缺（只有升级跳过、育儿袋、尊嘟假嘟、Boss 宝箱）。
- 场地有边界，不能无限往一个方向跑。
- 盾怪、冲锋、远程、弹幕墙需要不同的应对，单一 build 有明显短板。
- 每次 Boss 后有 20s 喘息期，节奏有松有紧。
- 局外难度"肥嘟嘟等级 1–10"（类似 Hades Heat）：通关后可开启，每级加一个负面规则，换更高结算倍率。

目标：首次通关率 < 10%，熟练玩家 3–5 局能通关一次。需要内测调参。

## 9. 抽象音效与"笑声连击"

- **笑声连击**：连杀数越高，奶蛙的笑声逐级升级：嘿嘿 → 哈哈 → 鹅鹅鹅 → 笑到岔气的抽气声。这是最核心的反馈。
- **语音台词**（队员自己录，或开发期先用 TTS 占位）："你胆子真是肥嘟嘟的""绷不住了""6""典""破防了""芭比Q了""栓Q""退！退！退！"。
- 命中音随机变调（±15%），同类音效同时最多 6 个，避免几百个怪一起叫变成噪音。
- 升级、金卡、大招各有专属音效；BGM 随阶段切换（入门轻松 → 地狱鬼畜）。
- 全部用 Web Audio API，音频压成 OGG/MP3 双格式（iOS Safari 兼容）。

## 10. 视觉风格

- 低多边形 + 卡通着色（toon shading）+ 描边，高饱和配色，奶黄色主角在灰紫色"emo 世界"里很显眼。
- 俯视约 55° 斜角透视相机，跟随玩家，大招时切近景。
- 伤害数字用"梗字"飘出（暴击显示"暴击！绷不住了"）。
- 怪物被击杀时做个小动作：乌云散开变晴天、周一变周五、差评变好评。

## 11. 技术方案

**选型：Three.js + TypeScript + Vite**，部署 GitHub Pages。

| 方案 | 包体/加载 | 手机网页表现 | 控制力 | 结论 |
|---|---|---|---|---|
| Three.js | 小（约 1–3MB） | 好，需要自己做优化 | 最高 | ✅ 选它 |
| Babylon.js | 中 | 好 | 高，自带更多 | 备选 |
| Unity WebGL | 大（10MB+） | 手机端加载慢、发热 | 高 | 不选 |
| Godot Web 导出 | 中大 | iOS Safari 有兼容问题 | 高 | 不选 |

**性能关键（目标：手机 400 怪 + 600 子弹 稳定 45+ FPS）**：
- 每种怪一个 `InstancedMesh`，一种怪一次绘制调用（[Three.js 论坛相关讨论](https://discourse.threejs.org/t/many-objects-caused-low-fps-can-we-optimize-it-without-losing-control-over-individual-mesh/76837/1)）。
- 热梗弹不用 TextGeometry（太贵），用**文字贴图图集 + 实例化广告牌面片**。
- 不用物理引擎，游戏逻辑在 XZ 平面上做 2D 圆形碰撞 + **空间哈希网格**。
- 全部对象池，游戏循环里不 new 对象。
- 手机端像素比上限 1.5，帧率掉了自动降分辨率、关描边。
- 固定步长逻辑更新（60Hz）与渲染分离。

**目录结构（草案）**：
```
src/
  main.ts              入口
  core/                游戏循环、时间、事件总线、对象池、空间哈希
  input/               键鼠、触屏双摇杆、手柄
  render/              场景、相机、实例化渲染、文字图集、特效
  game/
    player/            奶蛙、肥嘟嘟 AI
    weapons/           形态、改造、技能、进化
    enemies/           敌人行为、精英词缀、Boss
    director/          刷怪导演（读取 waves.json）
    progression/       经验、升级卡池、局外解锁
    ultimate/          大招 + 切镜演出
  audio/               音效管理、笑声连击
  ui/                  HUD、升级卡界面、结算
  data/                waves.json、upgrades.json、enemies.json（数值全部配置化，方便调平衡）
```

## 12. 开发里程碑

| 阶段 | 内容 | 可玩标准 |
|---|---|---|
| M0 核心循环 | 奶蛙移动射击、1 种怪、经验、升级三选一，三端操作 | 手机和电脑都能玩 3 分钟 |
| M1 build 系统 | 5 种形态、改造卡、6 个技能、进化 | 不同局玩出明显不同的流派 |
| M2 30 分钟 | 全部敌人、刷怪导演、精英、3 个 Boss、特殊事件 | 能完整打一局 |
| M3 招牌内容 | 肥嘟嘟 AI、大招切镜演出、笑声连击、全部音效 | 演示视频效果拉满 |
| M4 打磨 | 平衡调参、手机性能、结算/解锁、部署上线 | 评委扫码即玩 |

**如果时间很紧（比如 48 小时）的砍法**：形态只做 3 种，技能做 4 个，Boss 只做最终 Boss，肥嘟嘟只保留跟随打拳 + 嘲讽台词；**大招演出和笑声连击不能砍**，这是评委记住我们的点。
