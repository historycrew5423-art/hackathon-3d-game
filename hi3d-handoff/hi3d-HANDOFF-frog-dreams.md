# 奶蛙三重梦境 · 美术升级交接文档（hi3d-HANDOFF）

> 目标读者：接手做"美术风格大提升"的 AI / 美术。本文档是本游戏从立项到当前版本的全部设定、改动史、技术手段与已知问题。
> 运行入口：`dist/hi3d-index.html`（需 HTTP 服务打开，不能 file://）。源码在 `source/`。

---

## 0. 一句话
Three.js 手机网页游戏。主角"大奶蛙"在教室睡着，依次坠入三层梦境循环（每层 30 秒）：
**教室 → 庄周梦蝶（塔防） → 西游·白虎岭（开放世界清怪） → 坠梦隧道 → 堂吉诃奶蛙（跑酷追风车） → 回到庄周梦蝶……**
核心笑点：一切攻击都是"笑"——喷蝴蝶、喷"嘿/哈"字、哈字龙卷风、笑成面条、笑成光、笑到小怪灵魂出窍。目标：抽象、让人笑出声。

## 1. 硬约束（美术升级必须遵守）
1. **手机网页快速打开、稳定渲染**。当前整包 23.7MB（dist 解压）。目标别明显变大；单模型 ≤ ~2MB（meshopt + WebP 1024 + quantize）。
2. 手机操作：左侧虚拟摇杆 + 右侧圆形按键（跳跃/尬笑/按住狂笑/大招，第二关多一个「巨」法天象地）。电脑：WASD/方向键、空格跳、J 狂笑、K 大招、L 法天象地、Q 尬笑、P/Esc 暂停。拖动画面/鼠标转第三人称视角。
3. **主角必须稳定可见**：大奶蛙优先单独加载（重试 3 次、每次 40s 超时）；材质 clone、`frustumCulled=false`；第三关每帧强制 visible；龙卷风 sprite `depthTest:false, renderOrder:6`。任何新皮肤加载失败自动回退原装大奶蛙。
4. 所有新生成文件名 `hi3d-` 前缀，资源用相对路径。
5. 版权：不使用未授权影视原声/原曲。"鸡你太美"用代码合成律动 `audio.jiBeat()`；猴王笑声 `monkeyLaugh()`、"嘿" `monkeyHei()` 均为合成；"妈妈"音效来自用户交接包 `tang-mama.mp3`。高雅人士舞蹈用户要求"网上热门舞蹈原版"——当前用骨骼程序动作模拟（踮脚旋转+摇摆+鞠躬），没有使用原版动捕/音乐。
6. 第一关、第三关**不要出现孙悟空元素**（金箍、虎皮裙、金箍棒、猴王笑声只属于第二关）。离开第二关时 `main.enter()` 会隐藏 `journey.kit`。

## 3. 第一关 · 庄周梦蝶（`src/scenes/hi3d-ButterflyScene.js`）
**氛围参考**：用户提供的 AI 图（`reference/` 里的竖屏图）——淡蓝白天空、从左上斜射的光柱、天上一只巨大半透明水晶蝴蝶、云海中散布浮空小岛（樱花树、玻璃穹顶、瀑布从岛底挂下、茅屋窗内暖光）。用户评价早期版本"没有精细高级感、云雾缭绕感不够"。
**当前实现**：
- 天空 ShaderMaterial 渐变 + 太阳光晕 Sprite + 9 条加色光柱平面（canvas 渐变贴图）+ 天上 14 倍大水晶蝴蝶（双翼 pivot 扇动）。
- 主场：浮岛圆柱 + 草坪 + 湖（金属反射）+ 小路 + 荷叶荷花 + 两座亭子 + 樱花树（合并网格）+ 主岛边缘 5 道瀑布。
- 13 座浮空岛 `floatIsle()`：倒锥岩体 + 草顶 + 樱花 + 可选茅屋（暖窗）+ 玻璃穹顶 + 瀑布（滚动 canvas 贴图）。所有小件用 `chunk()` 合并为单网格顶点色，控制 draw call。
- 云海：70 个 canvas 云 Sprite 两层漂移 + 16 个雾 Sprite。花海 900 个 InstancedMesh。
- **美术升级空间最大**：岛体是低模锥体、云是 Sprite，可换成 Hi3D 生成的浮岛/茅屋 GLB、体积云 shader、bloom 后期、真实花草实例。
**玩法与技能**：
- 塔防：3 座精细楼阁塔（八角石台+台阶+3 重檐+金翘角+红柱+灯笼+双旗+顶部旋转发光水晶核心），每塔 100 血，大号血条。塔上站高雅人士：侦探企鹅、特工企鹅（雨伞）、袋鼠。
- 普攻（按住 J 狂笑）：奶蛙嘴里喷蝴蝶（先从嘴部"噗"出再弧线飞向最近塔），同时背上翅膀快速扇动，每扇额外扇出 2 只蝴蝶。蝴蝶 canvas 翅膀贴图 4 色。
- 大招 K「面条甩甩」：身体被笑软，Y 轴拉长 3.4 倍、XZ 变细、绕圈甩动 2.8 秒，每 0.22 秒对 7~8.5m 内塔/小怪/梗弹幕/雨伞造成伤害。（用户要求取代旧的"蝶群出击"）
- 高雅人士攻击：
  - 丢梗弹幕：对话框 Sprite（"这很难评""格局打开""尊嘟假嘟""蚌埠住了"等 18 条）飞向奶蛙，命中扣血并显示奶蛙吐槽回复；狂笑可撞碎。
  - 侦探企鹅：5 把伞扇形散射；特工企鹅：10 把伞环形回旋再追踪。伞是合并小模型，旋转飞行。
  - 袋鼠："你的胆子肥嘟嘟的"（用户口误，是肚子）——喷 3 只小袋鼠弹跳撞人，配 feidudu 音效。
  - 塔被打爆：塔件散落崩塌 → 塔上角色跳"高雅舞蹈"3.2 秒 → 下塔追着奶蛙打拳（自带 60 血血条，打死后"被蝴蝶抬走"）。
- 地面小怪（自绑骨 Hips/Spine/Head/Arm/Leg，`npcPose` 模式 walk/box/spin/bash/spit/dance），**必须正面冲向玩家**：
  - 小黄鸭"小黑子"（背篮球）：靠近先跳舞 + 合成"鸡你太美"律动，再铁山靠冲撞击退。
  - 鲸鱼女仆（蓝）：远程吐泡泡。
  - 负鼠：近身拳击。
  - 企鹅：陀螺旋转撞人。
- 梦核血量 100，归零重置并扣分。

## 4. 第二关 · 西游·白虎岭（`src/scenes/hi3d-JourneyScene.js` + `baihuling/hi3d-baihuling.js`）
- 场景：用户提供的"三打白骨精_白虎岭"Three.js 村庄场景（独立 renderer 先画背景，再画角色层）。已压缩：贴图 WebP、岩石低模 `rocks_low.bin`、HDR 天空。用户要求"开放世界、不要特别大"：可走半径 52m。用户曾要求参考《黑神话：悟空》风格——**这是美术升级重点**（当前村庄偏写实但灯光平、缺少黑神话的雾、体积光、苍凉色调）。
- 刷怪：在镜头背后 24~36m 外从地下升起，每 3 秒一波，最多 12 只。四个西游小怪（用户 Tripo 模型，减到约 3.2 万面）：
  - 哔哔喇叭布：不停旋转转圈撞人。
  - 咕咕嘎嘎：法师，保持距离不断喷"咕咕嘎嘎"字弹。
  - 香蕉猫：哭着周期性扑向你（banana-cry 音效）。
  - 我的刀盾（刀盾狗）：挥舞刀盾，daodun 音效。
  - 每只 100 血大号血条，头顶冒梗台词气泡。
- 普攻（按住 J）：美猴王奶蛙挥棒（近战 3.2m 扇形，扣 45）+ 扇形甩出 5 个"嘿"字弹 + 自动锁定最近小怪喷 2 个"哈"（锁定红圈）。配合成猴王"嘿"。血条打空 → 小怪狂笑停不下来 → 0.9 秒后传染 5.5m 内同伴 → 3.5 秒后灵魂出窍升天（半透明青色幽灵模型上飘）。
- 大招 K「七十二变」：3 秒内分出 72 只奶蛙（11 只骨骼动画近景 + 60 只 InstancedMesh 远景），复合狂笑喷"嘿"+合成孙悟空笑声，主角变成光球越来越亮，全屏发光，最后全图清怪。
- 第二大招 L「法天象地」：奶蛙 0.8 秒长到 7 倍，左右脚轮流抬起踩下（每脚踩扁 22m 内小怪 + 震屏 + 冲击波），最后一脚全图清；镜头拉远。
- 30 秒到点：地面放射状裂开（金色裂纹）、碎片连同小怪一起坠落 → 坠梦隧道。

## 5. 第三关 · 堂吉诃奶蛙（`src/scenes/hi3d-RunnerScene.js`）
- 三车道跑酷（左右换道、空格跳，起跳初速 8.6），地块池循环：麦田 / 村庄 / 云海三主题，远处借用"峡谷拱门"程序化岩拱。
- 风车巨人 = 用户模型"牛来"（交接包已绑骨）+ 背上 4 片风车叶 + 屋顶帽，在前方逃跑。血量 100（每倒一次换更厚血的下一个 +25）。被击倒：后仰倒地乱蹬，喊"妈妈"（tang-mama.mp3）。
- 普攻：按住 J 喷"哈"字龙卷风（36 个"哈"Sprite 螺旋上升），扣 9。
- 大招 K「捧腹天降」：巨型奶蛙从 22m 高空砸向风车，挤扁回弹，扣 70。
- 障碍（精细化后）：麦秆纹理干草垛+麻绳、木板拼桶+三道铁箍、尖头木栅栏+铁钉（全部 canvas 程序贴图，零下载）。头顶标签"思想包袱/禁止内卷"。

- 美术升级空间：风车叶片/帽子是基础几何、地块是简化麦田，可换 Hi3D 精细风车塔、西班牙拉曼恰风格场景。

## 7. 通用系统
- 血条 `src/game/hi3d-HpBar.js`：canvas Sprite，深色圆角底框+白描边、绿→黄→红渐变、名字+百分比，值变才重绘，`depthTest:false`。覆盖塔、所有小怪、追打的高雅人士、风车巨人、奶蛙（第三关）。
- 能量：狂笑充能，大招耗 25，法天象地耗 30（冷却 10s）。冷场机制：6 秒不笑画面去饱和。尬笑 Q：全场冻结 3 秒。
- 笑话图鉴：4 个成就卡（高雅但塔没了 / 灵魂比本人更活泼 / 风车拒绝下班 / 全世界都在替我尴尬），localStorage 保存最高分。
- 震屏 `app.shakeT`；特效 `fx.wave`（冲击波环）、`fx.hei`（嘿字粒子）；捧腹大笑 UI `laughUI`（旧版沿用的梗字雨）。
- 音效 `src/audio/`：合成音（tone/noise）+ 梗音频表 `hi3d-Memes.js`（nl-dupu、gugugaga、oiia、banana-cry、daodun、feidudu、shanshenbu、tang-mama 等，来自用户 zip）。
- 资源加载 `hi3d-Assets.js`：GLTFLoader + MeshoptDecoder；动物模型包一层 wrapper（`group.children[0]` 才是本体，转 -90°）；失败用程序代理体回退。

## 10. 用户反馈与改进历程（按时间）
1. 用旧"奶蛙缝合版"框架，去掉原场景，改三梦循环；用大奶蛙 + 旧捧腹大笑技能。
