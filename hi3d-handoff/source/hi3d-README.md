# 奶蛙 · 课间梦游指南

一个基于你提供的旧游戏改造的本地 Web 3D 喜剧原型。主角只用大奶蛙，保留旧版捧腹大笑的动作、动图、飘字和笑声。新角色和场景均来自本次提供的素材或可编辑程序化模块。

## 直接试玩

在 Hi3D 对话里打开 `hi3d-index.html` 旁的**浏览器预览**。进入后点击“趴下，开始做梦”。所有依赖均为本地文件，无需 CDN。不要使用 `file://` 直接双击入口。

1. 教室序幕约 4 秒，大奶蛙趴桌入睡。
2. **庄周梦蝶**：移动、狂笑，放蝴蝶攻打三座高雅塔；靠近来袭的评审团狂笑以保护课桌。塔倒后角色跳原创程序化滑步、摆身舞。企鹅、雨伞特工、袋鼠、鲸鱼女仆、篮球鸭和负鼠全部参与本梦。
3. **赛博西游**：同源大奶蛙精确 72 个，12 个带骨骼角色与 60 个静态烘焙实例，六组错相狂笑；“嘿”、声波、传染笑和灵魂出窍。四种西游特化小怪仍是明确占位，等待后续模型。
4. **堂吉诃奶蛙**：自动前进、三路换道和跳跃。麦田、倒悬村、云海依次出现；大笑蓄能后放龙卷风。命中会吹飞风车，每第三次命中则让它借风滑翔。
5. 每梦的玩法时间为 30 秒，暂停不计时。喷嚏转场和约 5 秒坠落通道另计。追逐结束后自动回到庄周梦蝶，继续循环；笑点和图鉴在每圈结束时结算。

## 操作

| 操作 | 电脑 | 触屏 |
|---|---|---|
| 移动／换道 | WASD、方向键 | 方向按钮或拖动摇杆 |
| 跳跃 | Space | 跳跃按钮 |
| 狂笑、蓄能 | 按住 J | 按住狂笑按钮 |
| 捧腹大笑、大招 | K，消耗 25 笑能，冷却 4.5 秒 | 大招按钮 |
| 三秒尬笑冻结 | Q，冷却 12 秒 | 尬笑按钮 |
| 转动西游镜头 | 拖动鼠标 | 本版移动优先 |
| 暂停 | Esc / P | 右上角暂停 |

暂停菜单可调音量、减少镜头震动、显示性能统计、重开和重新加载资源。离开窗口自动暂停，输入会清空。笑话图鉴与最高笑点保存在当前浏览器；浏览器禁止本地存储时会显示说明。

## 工程开发

入口本身是免构建的 Three.js ES module 项目，内置离线依赖。也提供 Vite 配置。解压工程后运行：

```sh
node hi3d-setup.cjs
npm install
npm run dev
```

`hi3d-setup.cjs` 只在不存在时创建 npm 必须使用的 `package.json`，不会覆盖已有项目配置。然后可用 `npm run build` 生成 `dist/`。Vite 构建保留相对资源路径。Hi3D 内仍使用客户端“浏览器预览”交付。

## 文件

- `src/scenes/`：教室、庄周梦蝶、赛博西游、追风车、坠落通道。
- `src/game/`：资源加载和回退、旧版输入适配、角色、静态场景导出。
- `src/legacy/`：从指定的 `nai_缝合版_naiwa_20261031.zip` 复用并适配的模块。
- `src/borrowed/`：从雨夜城市和峡谷拱门拆出的雨幕、噪声和拱门几何。
- `src/fx/`、`src/audio/`：池化文字／声波／龙卷风和音效。
- `public/assets/`：游戏直接使用的模型、两段奶蛙笑声和旧版技能动图。
- `assets_src/blender/hi3d-three-dreams.blend`：四个可编辑场景，包含同版模型和贴图；切换 Blender 场景查看。
- `assets_src/blender/hi3d-*-game.blend`：本次角色轻量副本的可编辑工程。
- `assets_src/snapshots/`：与浏览器相同几何的静态 GLB。场景节点附米制单位标记。
- `reports/hi3d-verification.json`：实际浏览器验收记录；`hi3d-final-*.png` 为运行截图。

原始高模没有被覆盖。游戏使用约 1.4–2.4 万面的角色副本和缩小的贴图；原始模型请继续保留在会话工作区。大奶蛙直接复用旧工程已优化的模型与骨架。

## 换入西游模型

在 `src/game/hi3d-Assets.js` 为四个新模型加入本地 URL，再在 `src/scenes/hi3d-JourneyScene.js` 的 `monsters` 创建处分别使用对应资源 ID。每个模型的根节点要保持足底居中、Y 轴向上、朝向 -Z；尺寸约 1.3–1.8 米。为嘴巴和特效保留 `MOUTH_SOCKET` / `FX_SOCKET`。灵魂应由对应模型的低细节副本生成，不能更换形象。新模型加载失败时仍保留可见占位与错误提示。

## 实测范围与当前边界

浏览器验收覆盖：真实键盘和触屏输入、攻塔及跳舞触发、精确 72 个实体、灵魂、24 块地面坠落、跑酷换道／跳跃／龙卷风命中、三主题路段连续性、30 秒循环、暂停、静音、图鉴和缺失模型回退。30 秒剧情用游戏本身的固定时间步加速检查，并非录像代替游戏。

测试采用本地 HTTP、关闭缓存、阻止外网资源。无头浏览器的 FPS 不是用户设备性能保证；尚未完成多款真实手机的性能测试。场景 GLB / Blender 是可编辑静态快照，实时动作、雨幕和粒子在游戏代码中，不声称是全部烘焙好的动画工程。

西游专用角色仍待用户提供；风车是带独立叶片、腿和表情挂点的可动原型。高雅舞蹈为本版原创程序化动作，未复刻某一未提供参考的网络舞蹈。没有加入线上多人、好友偷梦或其他五种游戏类型。
