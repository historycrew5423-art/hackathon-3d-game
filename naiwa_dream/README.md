# 奶蛙梦游记（naiwa · 梦境版）

语文课讲《庄周梦蝶》，奶蛙听着听着睡着了，一头栽进梦里。梦有三种，**每 30 秒换一种，越做越深**，做满 9 层下课铃响：

| 梦 | 玩法 | 嘴里喷什么 | 捧腹大笑变成 | 换到下一个梦 |
|---|---|---|---|---|
| 🦋 庄周梦蝶 | 塔防：课桌上睡着奶蛙的真身，高雅企鹅想戳破它的鼻涕泡把它吵醒 | “哈” | 蝴蝶笑：放出一群蝴蝶去打高雅塔，塔倒了企鹅就跳华尔兹 | 打个大喷嚏，全吹飞 |
| 🐒 赛博西游 · 三打白骨精 | 护送：七十二变，一群小奶蛙一起喷“嘿”；唐僧是牛来，一有危险就喊“妈妈” | “嘿” | 分身笑：72 个奶蛙一起狂笑，夹着猴子叫，小怪笑到灵魂出窍 | 笑到地震，地面裂开掉下去 |
| 🌀 堂吉诃奶蛙大战风车 | 跑酷：长了腿的风车巨人在前面跑，奶蛙在后面追 | “呼” | 龙卷笑：笑成龙卷风往前卷 | 风车扇一口大风，吹回庄周的梦 |

- **交接：** 怎么运行、操作说明、完成进度、没做完的事和下一步，见 `交接说明.md`。
- **试玩：** 在本目录双击 `Play-Windows.bat`（会自动打开浏览器），或者运行 `python -m http.server 8000` 再打开 `http://127.0.0.1:8000/`。不要直接双击 `index.html`。
- 底子是《罗密欧与朱丽叶 · 奶蛙缝合版》（`nai_缝合版_naiwa_20261031.zip`）：喷字打怪、3D 梗小怪、捧腹大笑、肥嘟嘟、闪身步、三种视角、声音分层、梗的节奏、手机横竖屏都沿用。四幕剧情和场景换成了三个梦。
- 这一版改了什么、每个素材从哪来，见 `梦境版说明.md`。

## 操作
| | 手机 | 电脑 |
|---|---|---|
| 走 / 跑酷时左右躲 | 手指按住拖 | WASD / 方向键 |
| 瞄准 | 横屏右手拖；竖屏第二根手指拖（不碰也会自动喷） | 鼠标 |
| 变身捧腹大笑 | 右下「变身」 | V |
| 肥嘟嘟（袋鼠蹦出来，怪全吹成气球） | 🦘 按钮（喷字攒满后发光） | F |
| 闪身步 | 走路时自动 | 空格 |
| 跑酷：跳 / 开船（往后喷一口往前冲） | 「跳」/「开船」按钮，手指往上推也是跳 | 空格 或 W / B |
| 切换视角 | 右上「视角」 | C |

## 网址参数（测试用）
`?auto=1` 自动玩；`?god=1` 不会死；`?len=秒数` 每个梦多长（默认 30）；`?dream=0/1/2` 从哪个梦开始；`?layers=数字` 做几层梦下课（默认 9）；
`?intro=0` 跳过开场的课堂；`?cam=1` / `?cam=2` 第三 / 第一人称开局；`?norevive=1` 关掉捧腹大笑复活；`?mute=1` 静音；`?debug=1` 显示帧数。

## 文件
- `index.html`、`src/`、`vendor/three/`（three.js r187，MIT）、`assets/`：游戏本体，纯静态网页。
  - `src/game.js` 通用玩法（走路、喷字、小怪、捧腹大笑、肥嘟嘟、界面、流程）；`src/dreamplay.js` 三个梦各自的玩法；`src/world.js` 三个梦的场景；`src/music.js` 合成的背景音乐。
- `scripts/`：处理模型、合成配音的脚本（参考用，运行游戏不需要）。
